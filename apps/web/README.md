# `@repo/web` — Inteligir marketing site

TanStack Start landing page, server-rendered on Cloudflare Workers. No
database, no auth — just the public-facing pitch for the product. Built with
vite (`@cloudflare/vite-plugin` + `@tanstack/react-start`) and styled with
Tailwind 4 via `@repo/ui`.

## Layout

```
src/
  router.tsx           Router factory (TanStack Start entry)
  routeTree.gen.ts     Generated route tree (committed; regenerated by vite)
  routes/
    __root.tsx         Document shell — head/meta, theme provider, header
    index.tsx          Landing page (download-URL loader)
    robots[.]txt.tsx   robots.txt server route
  components/
    site-header.tsx
    hero-orb.tsx       Three.js orb (via @repo/ui), client-only
    theme-provider.tsx next-themes wrapper
  lib/
    site-config.ts     Title, description, links — single source for metadata
  styles/globals.css   Inter Variable + @repo/ui/globals.css
public/                Static assets
wrangler.jsonc         Worker config (inteligir.com routes)
```

Shared components and styles come from `@repo/ui` (`@repo/ui/globals.css`,
`@repo/ui/components/*`). Keep page-specific bits here; promote anything reused
across apps into `packages/ui`.

## Dev

```bash
pnpm dev:web      # vite dev
```

## Build & deploy

```bash
pnpm --filter @repo/web build     # vite build (dist/client + dist/server)
pnpm --filter @repo/web start     # preview the production build
pnpm --filter @repo/web deploy    # build + wrangler deploy (needs CF auth)
```

Deploys run automatically from `.github/workflows/deploy.yml` on push to main
(requires the `CLOUDFLARE_API_TOKEN` repo secret). The desktop app
(`apps/desktop`) is the actual product; this is the landing page only.
