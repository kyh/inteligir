# Welcome to inteligir

This folder is your vault: plain markdown files that belong to you, versioned with git. Edit them here or with any other tool — changes show up either way.

Start with [[Getting Started with Moss]] for the full tour of what notes can hold, skim [[Use Cases]] for real workflows, or open [[Kitchen Sink]] to see every block in one place.

Press ⌘K to ask the agent anything about the note you are reading.
