# Changelog

What changed in Inteligir, the desktop app and the `inteligir` command line, newest first. Each release's notes on GitHub are its section here, word for word.

## Unreleased

Inteligir is now a library of everything you save: links, articles, videos, images, PDFs and files, beside the notes you write, in one folder on your Mac. Save from your browser, by pasting or dropping onto the window, or from your iPhone's share sheet; the Mac or iPhone you saved on reads each page without asking a model. Organize with folders and tags, or ask the agent to Tidy my library. It does the work of a bookmark manager like Raindrop and a notes app like Obsidian at once, and your writing keeps every block the editor had.

### Before you update

- **This is a new app, and your vault is now your library.** The folder you have opens as your library as it is: every note in it is an item, still a plain markdown file, and nothing in it is rewritten. The window now opens on a grid of everything in it rather than on the last note you had open, and the sidebar lists your folders and tags. Links and files you save from now on land in a new **Unsorted** folder. The examples of each kind of save and the new guides come with a new library only; in yours, Edit filing rules…, beside Tidy my library, starts your filing rules from the starter ones the first time you choose it. If the top folder of your library already holds a file named `AGENTS.md`, that file becomes your filing rules instead: Tidy my library follows it, Edit filing rules… opens it, and it no longer shows as a card. If it holds instructions for something else, move them to another file before you choose Tidy my library.
- **Comments don't carry over to highlights.** This version keeps highlights in `.inteligir/annotations/` and no longer reads `.inteligir/comments/`, so the comments you have don't show, and a resolved one loses that mark (there is no resolving any more). The passages they marked stay in your notes and show a dotted underline. To keep a comment's words, copy them into its note before you update; the old folder stays in your library, and in History, until you delete it.
- **Something too big to sync leaves your other devices.** A file that grows past 10 MB stays on the Mac it is on and shows "Only on this Mac" there; your other Macs and your iPhone see it deleted, and can restore its last version from Deleted.
- **Download this version from inteligir.com.** The version you have cannot update itself to this one: download Inteligir from inteligir.com and drag it into Applications over the one there. Later updates install from the app again.
- **Inteligir needs macOS 13.5 or later.** The app now runs on the Mac's own web engine instead of carrying a browser of its own, and what it brings in its place needs macOS 13.5. On an older Mac, keep the version you have: it keeps working.
- **Update every Mac and iPhone you sync.** Earlier versions stop syncing with your account once this one is out. They keep your library on the device, and pick up where they left off as soon as you update them. From now on, a version too old to sync says so and asks you to update, instead of failing without a reason.
- **Toggles, columns, dates and embeds are saved in a new, readable form.** A toggle is now written as `:::toggle` … `:::`, columns as `:::columns` with a `:::column` for each, a date as `@2026-08-22`, and a video, post, PDF or page as `![](its link)`, so each reads plainly in any other notes app. Ones saved by an earlier version open as the tags they were written with around their text, which no longer fold, sit side by side or open a calendar; to get the block back, insert it again from the `/` menu and move the text in.
- **Your window settings start over once.** The theme, the text appearance, the sidebar and panel widths and the spell check switch go back to their defaults the first time this version opens; set them again in Settings. File › Open Recent Library starts empty, and Debug logging in Settings › Advanced starts off. A message about an item two devices changed that you already saw can show once more. Your library, sign-ins and agents are untouched. On macOS 13, every library now shares one set of these settings.
- **Your actions on this Mac start over once.** The first time this version opens, it clears the actions this Mac kept, and they don't come back from your account, which no longer keeps actions. If an action's reply holds something you want to keep, copy it into a note before you update. Your library, your agents and your sign-in are untouched.
- **The library in the Inteligir folder of your home starts fresh once.** Every library now keeps its own sign-in, default agent and actions, that one included, so the first time this version opens it, it is signed out, with no default agent chosen and no earlier actions. Its items and their history are untouched, and your other libraries are as they were. Sign in again in Settings › Account.

### New

- **Your library, one card per item.** The window opens on a grid of everything you saved (links, pictures, PDFs, videos, sounds and notes), with each page's picture on its card and pinned items first. Choose All items, Unsorted, a folder or a tag in the sidebar to narrow it, and a kind (Links, PDFs…) above the grid to see just that kind. Click a card to select it, ⌘-click or ⇧-click to select more, and ⌘A to select everything shown; double-click or press Return to open one, and press Space for a quick look without leaving the grid.
- **Save a link by pasting it, dropping it or typing it.** Paste a link anywhere in the window, or drop links and files on it, and it is saved into the folder you're looking at, or Unsorted. A message says where, with Open, or that it's already in your library, with Show. ⌘P has Save link…, and typing a web address there offers to save it.
- **Your Mac fills in what you save, without a model.** A saved link fills in its title, site, author, cover picture and readable text from the page, on the Mac, without calling any model. When a page can't be read, the item says why, and Refresh from the page in ⌘P tries again. Saving a link you already have adds its tags and highlight to the item you have, rather than making a second one.
- **Keep a copy of the page.** In ⌘P, Info or the browser extension, Keep a copy of the page keeps the page as it looked beside the item, and it opens in the item's view.
- **Save from Chrome, Arc, Brave, Edge or Vivaldi.** The Inteligir extension saves the page you're on to Unsorted: click its toolbar button, or right-click a page, a link, an image or a selection. A selection is saved as a highlight on the page. Its popup has Keep a copy of the page, and Open Inteligir to bring the app forward. If the app is closed, a save opens it behind your browser and lands within half a minute. Nothing you typed into the page goes with a save: form fields and boxes you write in, such as an email you're writing, are left out. Get the extension from Settings › Library.
- **Any file up to 10 MB, not only pictures.** Drop a PDF, a video, a sound or any other file on the window and it becomes an item of its own. PDFs, videos and sounds open in the window, and a video or a song can be scrubbed.
- **An item opens full size.** A picture, a PDF, a video or a sound opens in its own viewer, a saved page opens as its article under where it came from with Open original, and a saved link whose page isn't read yet says "Not read yet", with Read it on this Mac for one saved on another device. Library in an item's top bar, or Escape, takes you back to the grid.
- **Info.** The panel's first tab shows what an item is, where it came from and when you saved it, and lets you change its address, description and tags. Select several items to tag, move, delete or ask the agent about them together.
- **Highlights with notes.** Select text in an item and press ⌘⇧H, or choose Highlight above the selection, to highlight it. A box opens for a note: press Return to save it, or Escape to keep just the highlight. A highlight added from the browser, an import or the agent lands on its passage in the item's text; one whose passage is gone is kept under a Highlights heading at the end.
- **Tidy my library.** At the top of Unsorted and in ⌘P, Tidy my library asks the agent to file and tag everything in Unsorted and everything untagged in one go, following your filing rules. Choose Edit filing rules… beside it, or in Settings › Agent, to write those rules in your own words. Undo changes takes a tidy back.
- **Ask the agent about what you see.** With the library showing, ⌘K asks about the items you selected, or the whole view when nothing is. The chip above the box names them; remove it to ask without them.
- **Bring your Raindrop bookmarks in.** Import from Raindrop…, in ⌘P, the Add menu and Settings › Library, takes a Raindrop backup's CSV file: every bookmark becomes an item in a folder named after its collection, with its tags, its note, its favourite pin and its highlights. You see what it will add before anything is added, the sidebar shows its progress with Stop, and each page's text and picture fill in over the next while.
- **Your library on your iPhone.** The iPhone app opens on your library: everything you saved, newest first, with covers, kinds to filter by, and a search over titles, sites and links. An item's menu opens the original page in Safari and shows its Info; pictures open full size and PDFs open in a viewer, and the PDFs, videos and other files you saved on your Mac are there too. A page's copy, and a picture or PDF inside a note, open in the viewer too.
- **Save from any app on your iPhone.** Share a page, a link or some text from Safari, YouTube, Mail or any app with "Save to Inteligir", or type one into "Save a link or a thought". It lands in Unsorted, even offline, and your iPhone fills in its title, picture and text itself as soon as it's online with the app open: no Mac needs to be awake. Until then its card says "Waiting to be read", and on your Mac "Not read yet". A page on the internet is read only over a secure (https) connection: for a plain http one the item says so, and Refresh from the page on a Mac reads it. A picture too large for the iPhone to open is saved as its link. Signing out on your iPhone asks first while links you saved there haven't been read, since no other device reads them unless you refresh them on a Mac. A highlight you made on the page before saving it lands on its passage. A link inside text you share is saved without the quotes, brackets or full stop around it, and the words around it become its note. When you tag it on your phone while a Mac refreshes it, the library keeps one version with every change in it.
- **Highlight on your iPhone.** Highlight in the toolbar above the keyboard highlights the selection; the note is optional.
- **Deleted brings everything back.** Deleting an item also deletes its picture, PDF or file, unless another item still shows it, and restoring the item from Deleted brings them back. Deleted lists files as well as notes, and restores each exactly as it was.
- **Terms of Use.** Inteligir now has Terms of Use, at inteligir.com/terms. They say what you agree to when you use the website and the apps: your library stays yours, the agent runs under your own Claude or ChatGPT plan's terms, and your online library is free up to about 1 GB.

### Changed

- **Our cloud's request log keeps less of each address.** The log and the traces Cloudflare keeps for us no longer record anything after the `?` in an address, so a sign-in code or a link's own query never lands there; inteligir.com/privacy says so.
- **Your vault is now your library, and everything in it is an item.** Settings › Vault is now Settings › Library, File › Open Vault… is Open Library…, and a note you write is still a note.
- **Comments are now highlights.** ⌘⇧A no longer comments on the selection: use ⌘⇧H to highlight it. The panel's Comments tab is now Annotations, which lists each highlighted passage with its note (click it to change it), its replies and Remove highlight; highlights whose words are no longer in the text are listed at the end. Each highlight remembers the words it was made on. On your iPhone too, comments are now highlights with an optional note.
- **The sidebar chooses what the library shows.** It lists your library, its folders, your tags and Deleted, in place of Recent, Files and Deleted. Clicking a folder, or a folder in an item's top bar, shows what is in it. The window opens on your library, not on the last note you had open, and Back takes you to what you had open before.
- **The panel's tabs are Info, Annotations, Actions and History.** What Metadata showed, Related and the properties included, is in Info.
- **⌘P reads "Search your library or run a command…".** Search across the vault… is now Search inside every item…, Deleted notes is Deleted, Pin note is Pin, and "Move note to folder…" is "Move to folder…", which moves any item. Show all results in the library shows everything matching what you typed in the grid.
- **Search looks at an item's address, not its properties.** Searching your library no longer finds words inside an item's properties; an item's address, site, author, description and tags are searched instead.
- **A file over 10 MB stays on the Mac it is on.** It shows "Only on this Mac" there; your other Macs and your iPhone see it deleted, and can restore its last version from Deleted.
- **Deleting an item on your iPhone takes the pictures and files only it shows with it.** Restore them together from Deleted on your Mac.
- **An item you have open stays open when something else moves it.** When the agent, another device or Finder renames or moves the item you're reading, the window follows it to its new place instead of going back to the library, even when your Mac takes a moment to read it there. A card you selected in the library follows it the same way.
- **The steps after a first run finish on your library.**
- **Callouts in the older form now show as written.** A callout from before the five kinds in the `/` menu now shows as its plain text, saved exactly as it was, and the links and tags inside it no longer count as links and tags. To give it a callout's look again, make it a Note, Tip, Important, Warning or Caution callout from the `/` menu.
- **Embed from URL takes a link on the web.** A link that does not start with https:// or http://, such as a file in your library, is now refused with a message: it opened as an image the next time the note opened. Add a file from your library as an image or a link instead.
- **A library that iCloud Drive, Dropbox or another service syncs, or a server of its own, is offered no account.** An account does nothing for such a library, so the first run skips its account step, and Settings › Account says so above its form. A library on a server of its own can still switch to your account in Settings › Advanced.
- **Your account's email shows as soon as you sign in.** The sync menu in the sidebar and Settings › Account name your account right away, where they showed the cloud's address until the app had asked who you are.
- **The app says which version it is when it syncs.** Each request the Mac app or the phone sends your account names its version, so a version too old to sync is told to update rather than answered wrongly. inteligir.com/privacy lists it.
- **Choosing a new password looks like the rest of the website.** The page a password-reset email opens now matches the sign-in page, and when its link has expired or was already used, it takes you straight to the page that sends a new one.
- **The privacy policy is reorganized, and says what saving fetches.** inteligir.com/privacy now follows the sections privacy law asks for, with an index at the top, and says how to ask us for a copy of your information, a correction or a deletion, including under U.S. state and European law. It now also says what your Mac or iPhone fetches when you save a link, what the browser extension and the share sheet hand over, and what a Raindrop import keeps, and that your conversations with the agent stay on the Mac they ran on and our cloud no longer carries them; how your account is deleted is the same as before, and every address the app talks to is still listed at the end.
- **Long notes and saved articles open, scroll and type faster.** Typing in a note thousands of lines long now keeps up with you, scrolling through one no longer stutters, and it opens sooner. Jumping to a far match, highlight or heading now lands on it at once rather than gliding there. A task's checkbox now reads as "Done" to VoiceOver.
- **Diagrams draw as you type, in the app's own colours.** A Mermaid diagram now redraws the moment you change it, in your note's font and the app's colours, and follows light and dark without redrawing. When it can't be drawn, it says why, and which line and column to look at when it can tell, and keeps the last drawing until you fix it. A link or picture written into a diagram is neither followed nor loaded, and a diagram is laid out a little differently than before.
- **A line reading `:::article` now holds a saved page.** A note with a line of just `:::article` at its top level, closed by a line of `:::`, now opens in Raw, without rich editing, since that pair is where a saved link keeps the page it read. To edit the note with rich editing again, change or remove that line. A `:::article` line you type is saved with a `\` in front, so it stays the text you wrote.

### Removed

- **Share with agent.** It is gone from a note's ⋯ menu. Ask the agent with ⌘K instead, which takes the item you have open or the items you selected.
- **Resolving a comment.** Highlights have no resolved state, and the "Show resolved" list is gone: remove a highlight once it has done its job.
- **Unlinked mentions.** Related, in the panel's Info tab, no longer lists notes that name this one without linking to it, and the Link button beside them is gone. To find the notes that name this one, search for its name, and type `[[` where it is written to make it a link.
- **Problems.** The Problems page in ⌘P is gone, with its lists of links that lead nowhere, missing images, notes nothing links to, and notes that share a name or an `id`. A link to a note that does not exist still shows dashed where you wrote it, and a missing image still shows as missing; Related, in the Info tab, still lists the items that link to this one. If you duplicate a note in Finder, ask the agent to give the copy an `id` of its own, so the two stop sharing their highlights.
- **Replace across your library.** Search inside every item… in ⌘P still lists every match, with match case and whole word, but no longer replaces them. To change a word in many notes, ask the agent, and Undo changes takes the whole edit back; to replace within one note, open it and press ⌥⌘F.
- **Daily notes and templates.** ⌘D and Daily note in ⌘P no longer open a note for the day, and New note from template…, Insert template… and the Templates group in the `/` menu are gone. Notes in your `notes/daily` and `templates` folders stay where they are, as ordinary notes, and `{{date}}`, `{{time}}` or `{{title}}` written in one now shows as a formula: replace it with the text you want. To start a note from one you kept, ask the agent to make a new note from it; to date a note, choose Date from the `/` menu.
- **The capture box on iPhone.** The box at the top of the iPhone app's home screen is gone, and your Mac no longer adds what you typed there to `Inbox.md`. To jot something down on your phone, type it into Save a link or a thought: it becomes a note in Unsorted. To have the agent do something with it, open it on your Mac and ask there with ⌘K. Your `Inbox.md` stays in your library as an ordinary note.
- **Asking your Mac's agent from your iPhone.** Ask agent is gone from the iPhone app, and so are its list of actions and the conversations it showed: the phone saves, reads and writes your library, and the agent runs on your Mac. To ask the agent, use ⌘K on your Mac; what it changes reaches your iPhone with the rest of your library. Let my phone ask this Mac is gone from Settings › Account on the Mac.
- **Actions on your other Macs.** An action now stays on the Mac that ran it: your other Macs no longer list it, and neither does your account. What it changed in your library still reaches every device. To read an action's conversation, open it on the Mac you ran it on. Sync threads now and its queue are gone from Settings › Advanced; there is nothing left to sync.
- **Linear and Context7 in one click.** Settings › Connectors now offers Notion and Exa in one click. A Linear or Context7 connector you already added keeps working; to add one again, enter its address under Add a connector.
- **Connected folders.** Settings › Connected folders is gone, and the agent is no longer told about folders outside your library. To point it at one, name the folder when you ask, or write a standing line such as "also look in Documents/Reports" into your filing rules (Edit filing rules…, in Settings › Agent), which the agent reads on every action. Or add those files to your library.
- **Adding a connector by command.** Settings › Connectors adds a connector by its web address, or in one click from its list, and Connect by with its Command and Arguments fields is gone. A connector that runs a program on your Mac, set up in Claude's or ChatGPT's own app, still shows there and can be removed.

### Fixed

- **Undo takes back a picture or a PDF the agent added, replaced or deleted.** Undo changes on an agent's reply used to leave the files it touched as they were; it now puts them back byte for byte, and keeps a picture the agent added that another item shows too.
- **A library too big for one sync now reaches your online library in several passes.** A library that grew past what one sync can send stopped as too large; it now sends its changes in steps.
- **Underlined text stays underlined.** Text you underlined with ⌘U came back as uneditable gray text the next time the note opened; it now opens underlined.
- **Tabs work inside toggles, columns, callouts, quotes and lists, and a tab can end with a list, a table or a callout, or start with a divider.** Tabs anywhere but the top of a note, a tab whose last block was a list, a table or a callout, and a tab whose first block was a divider opened as plain text after a save; they now stay tabs.
- **`<` before a number stays as you typed it.** A line like "under <50ms" was saved as `under \<50ms`; it is now saved as written.
- **A stray brace or tag no longer opens a note in Raw.** A note holding a lone `{`, a tag that is never closed (such as `<br>`), or a closing tag with nothing to close opened in Raw, without rich editing. It now opens with rich editing, and those characters stay exactly as you wrote them. Text in braces, like `{count}`, is now ordinary text you can edit.
- **Renaming a tag reaches every line of a callout, a quote or a list item.** A tag on the second line or later of a callout, a quote or a list item kept its old name when you renamed the tag; it now changes with the rest.
- **Notes open on iPhones with iOS 16.4 to 17.3.** On those versions the editor stopped before it could show a note; it now opens on every iPhone the app installs on.
- **The agent's own Inteligir commands work on every Mac.** The agent drives the app by typing `inteligir` commands; on a Mac without Node.js installed those failed, and now they run on what the app carries.
- **Messages you queued wait when your plan's usage limit is reached.** If Claude or ChatGPT stops an action because you've reached your plan's usage limit, or because you're signed out, the action now says so in plain words, and the messages you queued behind it stay queued instead of each failing the same way. Send again once the limit resets or you've signed in, and the oldest queued message goes first.
- **Text that reads like a date, a formula or the end of a block stays text.** Text you typed such as `@2026-08-22` or `{{2+2}}`, or a line of just `:::` inside a tab, turned into a date, a formula or the end of the tab the next time the note opened. It now stays the text you wrote, saved with a `\` in front so other apps read it the same way. To insert a date, choose Date from the `/` menu.
- **A ChatGPT action that runs out of room says it failed.** When a long conversation with ChatGPT outgrows what it can read at once, or ChatGPT stops for another reason, the action now ends as failed with ChatGPT's reason instead of finishing with that reason as its reply. To go on from a conversation that ran out of room, start a new action.
- **Nothing the agent started keeps running once it stops.** When you stop an action, quit, or an agent left idle is put away, the agent now gets a few seconds to close what it opened, and whatever still runs after that is ended. It used to be cut off at once, which could leave part of ChatGPT running on your Mac.
- **A step the agent tried that failed says so.** When a command or tool the agent used fails, its line in the action now reads Command failed or Tool failed, in red, instead of looking the same as one that worked.
- **An agent's separate replies within one action show as separate messages.** When the agent says what it is about to do, edits your library and then says what it did, each message now shows where it happened, before and after its edits, instead of being joined into one block above all of them. The same goes for its thinking. Conversations from before this update still show the way they did.
- **Sync details say why sync paused, not an earlier hiccup.** When sync paused because this Mac's changes and another device's could not be combined, an attempt that then could not reach the server left Settings › Advanced showing that connection error, and an attempt cut short by the agent's edits could leave it saying offline after it had reached the server. Settings › Advanced now shows the reason that still holds, and a sync that only found another device saved first shows no error while it catches up.
- **Saving never waits on items that are still downloading.** In a library kept in a folder that leaves files online until they're opened, like iCloud Drive with Optimize Mac Storage on, renaming a note that several such notes link to could hold every save until they had downloaded. Now the app opens only a few of those notes at a time, so what you type still saves and an item you open still opens.

### On the command line

- **`inteligir save <link|file|->` saves into the library.** It saves a web link, a file, or every web link piped to it with `-`, one per line, in order, with `--folder`, `--tags`, `--copy` (keep a copy of the page), `--html <file>` (save a page you already have without fetching it) and `--no-wait`.
- **`inteligir items` lists the library**, filtered by kind, tag, site, folder and date, and **`inteligir item show|find|refresh`** answers one item; `item find` matches a link however it is spelled. A link saved on your iPhone or another Mac shows `pending` until that device reads its page, since this Mac reads only what it saved or imported; `inteligir item refresh` reads it here.
- **`inteligir tag add|remove` tags and untags one item.** `inteligir tag notes` is gone: use `inteligir items --tag <tag>`.
- **`inteligir import raindrop <file>` imports a Raindrop backup's CSV.** `--dry-run` shows the plan and `--no-wait` returns once it starts; `import status` and `import cancel` follow it. An import that stopped on an error says why, and `--json` prints its job with `"state": "failed"`. From an agent's shell the import is refused as `FORBIDDEN`, since its Undo changes could not take it back: the agent can run `--dry-run` and ask you to choose Import from Raindrop… in the app.
- **`inteligir comment` is now `inteligir annotation`:** `list`, `add <path> <quote> --note <text>`, the new `edit <path> <id> <text>`, `reply` and `remove`. `add` highlights the passage in the item's text itself (`--occurrence` picks a later one), `--source` is gone and an agent's shell signs its entries, and `comment resolve` is gone. `vault restore --json` and `vault new-id --json` name the item's store `annotations` where they said `comments`.
- **`inteligir action new --preset tidy-library`** runs Tidy my library: it files and tags everything in Unsorted or with no tags.
- **`inteligir action changes --json` names each turn's `items`** beside its `paths`: what the app says the turn changed, each move once and no cover or original beside its item.
- **`inteligir vault restore <path> <sha>` brings back a deleted file**, and a deleted note with the files it held; `inteligir vault deleted` lists files, and names the note a file was deleted with.
- **`inteligir matches` no longer searches inside an item's properties.**
- **`INTELIGIR_DEBUG` accepts `items`**, which traces each save by path and url key.
- **`inteligir native-host` is the browser extension's door**, which the browser starts and the app sets up at each launch; never run it yourself.
- **`inteligir unlinked` is gone.** Find the notes that name a note with `inteligir search <name>`, and write `[[name]]` where it appears to link it.
- **`inteligir problems` is gone.** `inteligir backlinks <path>` still lists the notes linking into a note, and `inteligir vault new-id <copy>` still gives a copied note an `id` of its own.
- **`inteligir vault status` names the reason that still holds.** `lastError` is now always the current state's own message: a pass that reaches the remote clears an older one, a merge that still cannot be combined says so again, and a push that lost a race to another device's reports none.
- **Every vault's data dir is its own.** The default vault's (`~/Inteligir`'s) now sits beneath `~/.inteligir/vaults/` like any other's, keyed by the folder's physical path, so a folder reached through a symlink or typed in another case is one vault with one data dir. `inteligir status` no longer marks a data dir as the vault's own, and its `--json` drops `dataDirScope`.
- **`inteligir folders` is gone**, with Settings › Connected folders, and an agent's shell no longer has `INTELIGIR_CONNECTED_DIRS`. Name the folder in what you ask the agent, or in the library's `AGENTS.md`.
- **`inteligir serve` no longer warns about settings it does not read.** `INTELIGIR_AGENT_MODEL` and the `agentModel` and `vaultRemote` keys in `config.json` are ignored silently, like any other setting the app does not read.
- **`inteligir interactions` is gone, and so is `inteligir action wait --until-input`.** An action's approvals are answered in the app, on the action. `inteligir action show` still lists the approvals an action is waiting on, with what each would allow, and `inteligir action wait` still names them on stderr and keeps waiting until someone answers in the app or it times out; nothing exits 4 any more. With `--json`, `action show` reports each approval's `decision`.
- **`inteligir cloud login` is gone.** Sign the app in to your account from Settings › Account. `inteligir cloud status` still says whether this install is signed in, and points to Settings › Account when it isn't, as `inteligir vault status` does for the hosted vault.
- **`INTELIGIR_AGENT=acp` replaces `INTELIGIR_AGENT=auto`.** The mode that runs the agents the app carries is named for them, and `auto`, in the variable or as `config.json`'s `agent`, now stops the server at start-up. `inteligir status` says `Agent: acp`, `scripted` or `off`, with the reason when the agent can't start, and `inteligir agents default` names the harnesses there are when given one it doesn't know.

### On the command line

- **`inteligir vault write` no longer overwrites a note silently.** It now needs exactly one of `--if-absent` (create only), `--expected-hash <hash>` (replace only if the note still holds what you read; `inteligir vault read --json` prints the hash) or `--overwrite` (replace whatever is there). A script that relied on the old behaviour needs `--overwrite`. It also refuses an empty or interactive stdin: pass `--content ''` when you mean to empty a note.
- **A browser tab signs in only through a one-time link.** Opening the server's address, or a bookmark of it, now shows a signed-out page instead of your notes. `inteligir serve --open` still opens a signed-in tab; for another one, run `inteligir open` or use File › Open in Browser in the app. Each link works once and expires after five minutes. - **The command line and the app must be the same release.** An `inteligir` installed from npm refuses to talk to a server of another version (exit code 3) and names both versions, and the app no longer takes over a running `inteligir serve` of another version. Update both together.
- **Flags go after the command.** `inteligir --json vault read notes/a.md` is refused; write `inteligir vault read notes/a.md --json`. Extra words and unknown flags are refused too, where they used to be ignored, and so are extra words after `--`.
- **The model setting is per agent.** `INTELIGIR_AGENT_MODEL` and the `agentModel` key in `config.json` are no longer read, because one model name was handed to both agents. Set `INTELIGIR_CLAUDE_MODEL` or `INTELIGIR_CODEX_MODEL`, or `"agentModels": { "claude": "…", "codex": "…" }` in `config.json`. The server warns at start-up when it finds the old setting.
- **`inteligir connectors` is gone.** Add and remove connectors in Settings › Connectors, or with Claude Code's `claude mcp add --scope user` or Codex's `codex mcp add`, which edit the same list; a script that ran `inteligir connectors add` needs one of those instead.

- **The app's own git runs skip your vault's git hooks.** A hook in the vault (`pre-commit`, `commit-msg`, `post-commit`, `pre-rebase`, `pre-push` and the rest) could refuse, stall or rewrite every automatic commit and sync. Your own commits and pushes still run them.
- **`vaultRemote` in `config.json` is no longer read.** It applied to every vault the app opened. A vault now syncs with its own repo's `origin`, which it keeps when you sign in: run `inteligir vault remote <url>`, or pin one with `INTELIGIR_VAULT_REMOTE`. The server warns at start-up when it finds the old key.
- `inteligir vault remote` prints where the vault syncs; `inteligir vault remote <url>` makes a git server of your own the vault's `origin`, and `inteligir vault remote account` goes back to your account's hosted vault. `inteligir vault status --json` now carries `externalSync` in every state, and `remoteSource` says `pinned` when `INTELIGIR_VAULT_REMOTE` decides, which refuses a change.
- `inteligir vault open` says when another service syncs the folder or it has a git remote of its own, and `--json` carries both as `externalSync` and `remote`; `inteligir vault status` names the service too.
- **A sync no longer stops in a `conflict` state.** When a rebase meets a note both devices changed, the pass merges instead and pushes. `inteligir vault status` prints a line for each note it settled that way since the server started, and `--json` carries them as `conflicts`, beside this device's name as `device`; the `conflict` state and its `conflict` field are gone. Every commit the app makes names this device as its committer: the name it signed in under, else the Mac's own name.
- `inteligir open` opens another signed-in browser tab; `inteligir action list` pages with `--limit` and `--cursor`, filters with `--doc` and `--running`, and leaves archived actions out unless you pass `--archived`; `inteligir action wait` names an approval it is waiting on, and `--until-input` exits 4 when one arrives; `inteligir action changes` lists the notes each of an action's turns changed, and `inteligir action undo` takes one turn's changes back while keeping every edit made since, naming any note it had to leave as it is; `inteligir agents list` shows which agents are installed and signed in.
- **A browser tab whose sign-in stopped working**, say after the server restarted, shows one signed-out notice instead of an error for every request.
- **`inteligir serve`** refuses to start a second server on the same data folder, and closing its terminal still saves pending changes to the vault.
- **`inteligir open`** against a server started without the app's interface says how to fix it, instead of opening a link that leads nowhere.
- **`inteligir vault remote account`** no longer reports success when the vault will sync nowhere yet.
- **`inteligir action undo`** says so when nothing of a turn could be undone, and points at `--turn`.

### Security

- Content inside a note, such as an HTML block, can no longer reach the app's local server with the app's own access.
- A link in a note opens only when it is an `http` or `https` address.
- The installed app can no longer be started as a plain Node.js interpreter, and its cookies are encrypted on disk.
- The installed app checks its bundle's integrity when it starts and loads its code only from that bundle.
