## Why this matters

Four small, independent hygiene items: (1) `sync-manager.ts`'s header claims
sync is "NOT wired into the live boot path" while `create-host.ts` starts it —
a stale decision doc that misleads anyone auditing the sync surface; (2)
`vitest` is declared independently in five workspaces instead of the pnpm
catalog that exists precisely for shared toolchain deps; (3) `apps/mobile` is
the only app without a README (and the one with the most environment setup);
(4) `apps/cloud/worker-configuration.d.ts` is 14,655 generated lines that
pollute diffs and repo searches.

## Steps

### Step 1: Fix the stale sync-manager header

Rewrite the two stale lines to match reality, e.g.:

```
// OFF BY DEFAULT at runtime: create-host starts the SyncCoordinator at boot,
// but it constructs + runs the engine only when sync is enabled in config AND
// a bearer token is present (see create-host.ts and sync-coordinator.ts).
```

**Verify**: `grep -n "create-host does not construct" packages/features/src/server/sync/sync-manager.ts` → no matches

### Step 2: Catalog vitest

Add `vitest: ^4.1.7` under `catalog:` in `pnpm-workspace.yaml`; change the
five package.json declarations to `"vitest": "catalog:"`. Run `pnpm install`.

**Verify**: `grep -rn '"vitest"' apps/*/package.json packages/*/package.json` → every hit is `"catalog:"`; `pnpm test` → passes as before

### Step 3: apps/mobile/README.md

Write a README mirroring the other apps' tone/length (read
`apps/cloud/README.md` for the register): what the app is (sync/read/light-
edit companion, no agent), prerequisites (simulator or device + dev client),
run commands (verify against `apps/mobile/package.json` scripts), how sync
auth works (email+password against the coordinator URL), what's deliberately
absent (rich editor, custom-MDX rendering, agent), test command. Facts in
"Current state" above — do not invent capabilities.

**Verify**: file exists; every command in it copy-paste-runs (spot-check `pnpm --filter @repo/mobile test`)

### Step 4: Mark the generated d.ts

In `.gitattributes` (create at repo root if absent):

```
apps/cloud/worker-configuration.d.ts linguist-generated=true -diff
```

**Verify**: `git check-attr diff apps/cloud/worker-configuration.d.ts` → `diff: unset`

`apps/desktop/src/renderer/editor/kits/kit-utils.tsx`. (Also `plans/*.md`

ignored and follow that mechanism) instead of formatting it; if hand-written,
